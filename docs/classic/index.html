聽共享的 Library

Jeff 分享了一個名為 Library 的 Google 雲端硬碟資料夾 （同樣是 listen/ + ebooks/ 的結構）。 Kerry 和 Daryl 用自己的 Google 帳號登入。這一頁只讀取雲端硬碟，不會上傳你的書。

  1. 按用 Google 登入。播放器會載入名為 Library 的資料夾（包含「與我共用」）。
  2. 從書架播放。音檔從雲端硬碟串流。
  3. 本機備援：按改用本機資料夾（iPhone 請先在「檔案」裡下載）。
